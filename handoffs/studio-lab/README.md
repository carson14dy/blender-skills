# Roof Studio Lab

A copy of Roof Layer Studio, merged with the latest studio build, with a Lab tab that tests four free tools on the studio's measured house: model-viewer (AR), the three.js WebGPU renderer, 3d-tiles-renderer (neighbourhood from City of Sioux Falls 3D solids) and Spark (Gaussian splats from USGS 3DEP lidar coloured with NAIP 2025).

- Live page (private to the owner): https://claude.ai/artifact/588SfLYHjaPoa6Wd2eGKak
- `site/`: a full backup of the published page (51 files), ready to republish.
- How to use, test, rebuild, merge and publish it: the `roof-studio-lab` skill in `.claude/skills/roof-studio-lab/`, whose `scripts/` hold the data-build tools and the CSP test harness.
- Findings, verdicts and ranked project improvements: `reports/Studio lab tool tests.md`.
